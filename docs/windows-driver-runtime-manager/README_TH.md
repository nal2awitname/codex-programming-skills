# คู่มือ Driver & Runtime Manager (ตัวจัดการไดรเวอร์และรันไทม์)

โปรแกรมหน้าต่าง (GUI) สำหรับ Windows 10/11 ที่ตรวจเครื่องอย่างละเอียด ตรวจชุดไดรเวอร์ทั้งหมด ดาวน์โหลดและติดตั้งไดรเวอร์
จากผู้ผลิตก่อน แล้วจึงติดตั้งไดรเวอร์ที่ Microsoft รับรองซึ่งใหม่กว่า พร้อมรันไทม์และโปรแกรมเสริมสำหรับเล่นเกมและทำงาน
เลือกได้ทีละรายการด้วยช่องติ๊ก มี log ละเอียด ทำความสะอาดหลังติดตั้ง และรายงานความเข้ากันได้

ไฟล์ทั้งหมดอยู่ที่ [skills/windows-driver-runtime-manager](../../skills/windows-driver-runtime-manager/SKILL.md)

## เริ่มใช้งาน

1. ดาวน์โหลดโฟลเดอร์ `skills/windows-driver-runtime-manager/scripts` (ทั้ง 4 ไฟล์ต้องอยู่ในโฟลเดอร์เดียวกัน)
2. ดับเบิลคลิก `Start-DriverRuntimeManager.cmd` แล้วกด "ใช่" ที่หน้าต่าง UAC (ต้องใช้สิทธิ์ Administrator)
3. โปรแกรมจะสแกนเครื่องและตรวจหาอัปเดตให้อัตโนมัติ (การค้นหา Windows Update อาจใช้ 1–5 นาที หน้าต่างยังใช้งานได้ระหว่างรอ)
4. ตรวจแต่ละแท็บ ติ๊กเลือกรายการ แล้วกด **▶ ติดตั้งที่เลือก** ระบบจะแสดงลำดับที่จะติดตั้งให้ยืนยันก่อน

ไม่ต้องติดตั้งโปรแกรมใดเพิ่ม ใช้ Windows PowerShell 5.1 ที่มากับ Windows (รองรับ PowerShell 7 ด้วย)
ถ้าไฟล์ถูกบล็อกเพราะดาวน์โหลดจากอินเทอร์เน็ต ให้คลิกขวา > Properties > Unblock หรือรัน `Unblock-File` กับไฟล์ทั้งหมด

## แท็บในหน้าต่าง

| แท็บ | สิ่งที่ทำ |
| --- | --- |
| 1. ตรวจระบบ | ข้อมูลเครื่องอย่างละเอียด (Windows/บิลด์/วันหมดการสนับสนุน, ผู้ผลิต/รุ่น/BIOS/เมนบอร์ด, CPU/RAM/การ์ดจอ/ดิสก์/เครือข่าย, Secure Boot/TPM/Memory Integrity/BitLocker/Test Signing, แผนพลังงาน, บริการ, winget) และตารางความเข้ากันได้ (ผ่าน/เตือน/ไม่ผ่าน) |
| 2. ไดรเวอร์และอัปเดต | ตารางอุปกรณ์และไดรเวอร์ทุกตัว (ลำดับติดตั้ง ผู้ให้ไดรเวอร์ เวอร์ชัน วันที่ ระดับการรับรอง สถานะ) กรองและค้นหาได้ ดับเบิลคลิกดูรายละเอียด Hardware ID; ด้านล่างคือรายการอัปเดตให้ติ๊กเลือก |
| 3. รันไทม์และโปรแกรมเสริม | Visual C++ 2005–2026, .NET Desktop Runtime ทุกรุ่นที่รองรับ, .NET Framework 3.5/4.8.1, DirectX, XNA, GameInput, WebView2, PowerShell 7, Windows Terminal, PowerToys, Sysinternals, 7-Zip, Game Mode, HAGS, แผนพลังงาน — มีปุ่มชุด แนะนำ/เล่นเกม/ทำงาน/ทั้งหมด |
| 4. ติดตั้งจากไฟล์ | เพิ่มไฟล์/โฟลเดอร์หรือลากมาวาง รองรับ .inf .exe .msi .msp .msu .cab .msix/.appx .zip .7z .rar .iso .vhd .bat .cmd .ps1 .reg .ppkg แก้ตัวเลือกติดตั้งเงียบได้ |
| 5. ทำความสะอาด | เลือกสิ่งที่จะลบหลังติดตั้ง (เฉพาะไฟล์ที่สร้างระหว่างรอบนี้) |
| 6. บันทึก (Log) | log สดทุกขั้นตอน ปุ่มเปิดโฟลเดอร์ log และรายงานล่าสุด |

แถบล่าง: สร้างจุดคืนค่าก่อนติดตั้ง, สำรองไดรเวอร์เดิม, รีสตาร์ทหลัง BIOS/ชิปเซ็ตแล้วทำต่ออัตโนมัติ, รีสตาร์ทเมื่อเสร็จ,
อนุญาตไฟล์ที่ไม่มีลายเซ็น, โหมดทดลอง (ไม่ติดตั้งจริง — แนะนำให้ลองก่อนครั้งแรก), ปุ่มหยุด (หยุดหลังรายการที่กำลังทำงานจบ)

## ลำดับการทำงานที่โปรแกรมใช้

1. เตรียมระบบ (winget) และสร้างจุดคืนค่า
2. **อัปเดตจากผู้ผลิตเครื่องก่อน** — Dell Command | Update, Lenovo System Update, HP Image Assistant ทำงานอัตโนมัติ;
   ยี่ห้ออื่น (ASUS, MSI, Acer, Gigabyte, HP/Lenovo รุ่นผู้ใช้ทั่วไป ฯลฯ) จะเปิดเครื่องมือหรือหน้าดาวน์โหลดทางการให้
3. เครื่องมือผู้ผลิตชิ้นส่วน (Intel/NVIDIA/AMD) ถ้าเลือก
4. ไฟล์ที่คุณเพิ่ม เรียงตามที่ผู้ผลิตแนะนำ: BIOS → ชิปเซ็ต → Management Engine → Storage → กราฟิก → เสียง → LAN/Wi-Fi → Bluetooth → USB → อินพุต → กล้อง → อื่น ๆ
   (ถ้า BIOS/ชิปเซ็ตต้องรีสตาร์ท จะรีสตาร์ทแล้วเปิดโปรแกรมทำต่อให้อัตโนมัติ)
5. **ไดรเวอร์ที่ Microsoft รับรองจาก Windows Update** — ค้นหาใหม่หลังขั้นผู้ผลิต และติดตั้งเฉพาะรุ่นที่ใหม่กว่าของในเครื่อง
6. รันไทม์ (ดาวน์โหลดจาก Microsoft โดยตรง ตรวจลายเซ็นดิจิทัลก่อนติดตั้ง และอัปเดตเฉพาะเมื่อมีรุ่นใหม่กว่า) → โปรแกรมเสริม → ปรับแต่ง
7. ทำความสะอาด → ตรวจเครื่องซ้ำ → รายงานความเข้ากันได้ → รีสตาร์ท (ถ้าเลือก)

## ระดับการรับรองไดรเวอร์ที่แสดง

| ข้อความ | ความหมาย |
| --- | --- |
| WHQL — Microsoft รับรอง (ผ่าน HLK) | ผ่านการทดสอบความเข้ากันได้ของ Microsoft แล้ว (ดีที่สุด) |
| Microsoft ลงนามแบบ Attestation | Microsoft ลงนามให้แต่ยังไม่ผ่านชุดทดสอบ HLK |
| มากับ Windows | ไดรเวอร์มาตรฐานของ Windows |
| ผู้ผลิตลงนามเอง (ไม่ใช่ WHQL) | มีลายเซ็นของผู้ผลิต ควรหาเวอร์ชัน WHQL ถ้ามี |
| ไม่มีลายเซ็น / ลายเซ็นไม่ถูกต้อง | เสี่ยง ควรเปลี่ยนเป็นไดรเวอร์ที่มีลายเซ็น |

## ใช้แบบคำสั่ง (ไม่มีหน้าต่าง)

เปิด PowerShell แบบ Administrator ในโฟลเดอร์ `scripts`:

```powershell
# ตรวจระบบอย่างละเอียด + ตรวจอัปเดตจากผู้ผลิตและ Windows Update แล้วออกรายงาน
powershell -ExecutionPolicy Bypass -File .\DriverRuntimeManager.ps1 -Mode Scan -CheckUpdates

# ดูลำดับและคำสั่งทั้งหมดก่อน (ไม่ติดตั้งจริง)
powershell -ExecutionPolicy Bypass -File .\DriverRuntimeManager.ps1 -Mode Install -Preset gaming -IncludeOem -IncludeWindowsUpdateDrivers -DryRun

# ติดตั้งจริง: ชุดเล่นเกม + อัปเดตผู้ผลิต + Windows Update + ไฟล์ไดรเวอร์ (คั่นหลายไฟล์ด้วย ;) แล้วรีสตาร์ท
powershell -ExecutionPolicy Bypass -File .\DriverRuntimeManager.ps1 -Mode Install -Preset gaming -IncludeOem -IncludeWindowsUpdateDrivers -Files "D:\Drivers\chipset.zip;D:\Drivers\lan" -Reboot

# ติดตั้งเฉพาะรายการ (id จากแคตตาล็อก คั่นด้วย ,)
powershell -ExecutionPolicy Bypass -File .\DriverRuntimeManager.ps1 -Mode Install -Preset none -Items "vc14-x64,vc14-x86,directx-jun2010"
```

ตัวเลือกอื่น: `-NoRestorePoint`, `-NoCleanup`, `-AllowUnsigned`, `-Root <โฟลเดอร์เก็บ log>`, `-Resume`, `-ShowConsole`
รหัสออก: 0 = ไม่มีรายการล้มเหลว, 1 = มีรายการล้มเหลว (ดูรายงาน)

## ไฟล์ log และรายงาน

- Log: `C:\ProgramData\DriverRuntimeManager\Logs\DRM_<วันเวลา>.log` (ภาษาไทย UTF-8) และ log ของผู้ผลิต `OEM_*.log`, `*.msi.log`
- รายงาน: `C:\ProgramData\DriverRuntimeManager\Reports\DRM_Report_<วันเวลา>.html` และ `.json` — เปิดให้อัตโนมัติหลังติดตั้ง
- สำรองไดรเวอร์ (ถ้าเลือก): `C:\ProgramData\DriverRuntimeManager\Backup\<วันเวลา>` คืนค่าด้วย `pnputil /add-driver <โฟลเดอร์>\*.inf /subdirs /install`

## แก้ปัญหา

| อาการ | วิธีแก้ |
| --- | --- |
| ไม่พบ winget | ติ๊ก "App Installer (winget)" ในแท็บรันไทม์ หรือติดตั้ง App Installer จาก Microsoft Store |
| ค้นหา Windows Update ไม่ได้ | ตรวจว่าบริการ Windows Update ไม่ถูกปิด (ดูหมวด "บริการ" ในแท็บตรวจระบบ) และนโยบายองค์กร/WSUS |
| ตัวติดตั้ง EXE ค้าง | ตัวเลือกติดตั้งเงียบอาจไม่ถูกต้อง ลบช่อง "ตัวเลือก" ให้ว่างเพื่อเปิดหน้าต่างผู้ผลิตแล้วกดเอง |
| ไฟล์ถูกข้าม "ไม่มีลายเซ็น" | ใช้ไฟล์จากเว็บผู้ผลิตโดยตรง หรือเปิด "อนุญาตไฟล์ที่ไม่มีลายเซ็น" เมื่อมั่นใจแหล่งที่มา |
| อุปกรณ์ยังมีปัญหาหลังติดตั้ง | ดับเบิลคลิกอุปกรณ์เพื่อดู Hardware ID แล้วค้นไดรเวอร์จากเว็บผู้ผลิตเครื่อง/ชิ้นส่วน หรือรีสตาร์ทก่อน (รหัส 14) |
| ต้องการยกเลิกการรีสตาร์ทอัตโนมัติ | รัน `shutdown /a` ภายใน 60 วินาที |
| ติดตั้งแล้วเครื่องมีปัญหา | ใช้ System Restore คืนค่าไปจุดที่โปรแกรมสร้างไว้ก่อนติดตั้ง |

## ข้อจำกัดที่ควรรู้

- เครื่องมือของ Dell/Lenovo/HP ทำงานอัตโนมัติเฉพาะรุ่นที่ผู้ผลิตรองรับ ยี่ห้ออื่นต้องกดในโปรแกรม/เว็บของผู้ผลิตเอง
- ไดรเวอร์การ์ดจอ NVIDIA/AMD รุ่นล่าสุดดาวน์โหลดจากเว็บผู้ผลิต (หรือ NVIDIA App/AMD Software) แล้วเพิ่มในแท็บติดตั้งจากไฟล์
- Visual C++ 2005–2013 หมดการสนับสนุนจาก Microsoft แล้ว ติดตั้งเมื่อเกม/โปรแกรมเก่าต้องใช้
- วันหมดการสนับสนุนของ Windows อ้างอิงข้อมูลในแคตตาล็อก (อัปเดตล่าสุด 2026-11-10) ควรอัปเดตเมื่อ Microsoft ออกรุ่นใหม่
- ผลทดสอบอัตโนมัติรันบน GitHub Actions (Windows Server) และ Linux ยังต้องลองบนเครื่องจริงของคุณด้วยโหมดทดลองก่อนครั้งแรก
