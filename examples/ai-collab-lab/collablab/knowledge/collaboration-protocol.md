# Team collaboration protocol
Kind: article
Keywords: collaboration, protocol, handoff, coordinate, teamwork, ทำงานร่วมกัน, ประสานงาน, ส่งต่องาน

How agents in AI Collab Lab work together:

1. The coordinator turns each user request into tasks on the board with clear titles, an assignee and dependencies. Every task description starts with `Project: <slug>` and `Request: <text>`.
2. Start a task by moving it to in_progress, leave short notes while working, and finish by setting status done with a result that says what was produced and where.
3. Hand off explicitly: send a direct message naming the file or task the next person needs.
4. Publish decisions and reusable values as blackboard facts (for example `<slug>.recipe` or `<slug>.module`).
5. When blocked, set the task to blocked with a note and message the coordinator; the coordinator asks the user when the team cannot resolve it.
6. Use polls for go/no-go decisions that need more than one opinion.
7. Keep messages short. Put long content in workspace files and link them by path.
