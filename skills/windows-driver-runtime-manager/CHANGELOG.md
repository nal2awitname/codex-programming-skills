# Changelog

รายละเอียดข้อบกพร่องแต่ละรายการอยู่ใน [references/known-issues.md](references/known-issues.md)

## 1.1.0 — 2026-11-10

### เพิ่ม
- ฐานข้อมูลรหัสข้อผิดพลาด `scripts/errors.json` (MSI, Windows Update, WUSA, DISM, pnputil, winget, MSIX, Dell Command | Update, HP Image Assistant และรหัสปัญหาของอุปกรณ์) — ทุกรายการที่ล้มเหลวมีความหมายภาษาไทยและวิธีแก้ใน log หน้าต่าง และรายงาน
- โหมด `-Mode Diagnose` และปุ่ม "รวบรวมข้อมูลดีบัก (zip)": สรุประบบ อุปกรณ์ที่มีปัญหา log ผลลัพธ์คำสั่งที่ล้มเหลว รายงานดิบของ OEM setupapi.dev.log Event Log และ Driver Store โดยซ่อนชื่อเครื่อง ชื่อผู้ใช้ และ Serial
- เก็บผลลัพธ์เต็มของคำสั่งที่ล้มเหลวเป็น `Logs\Output_*.txt`
- ค้นหาไดรเวอร์ที่ Microsoft รับรองใน Microsoft Update Catalog จาก Hardware ID (คลิกขวาที่อุปกรณ์ และลิงก์ในรายงาน) พร้อมคอลัมน์ "วิธีแก้"
- บันทึก/โหลดชุดที่เลือก (`-SelectionProfile`, `-ExportProfile`, ปุ่มในหน้าต่าง) เพื่อใช้ซ้ำกับหลายเครื่อง
- ตรวจไดรเวอร์ผู้ผลิตที่เก่ากว่า 3 ปีในตารางความเข้ากันได้
- แสดงเวอร์ชันในหน้าต่าง log และรายงาน (`Get-DrmVersion`)
- CI: ทดสอบชุดดีบัก (ต้องไม่มีชื่อเครื่องหลุด), ตัวเปิดจากโฟลเดอร์ที่มีวงเล็บ, ติดตั้งรอบสองต้องไม่ติดตั้งซ้ำ, smoke test ของหน้าต่างครอบคลุมชุดที่เลือกและชุดดีบัก

### แก้ไข
- DRM-009 ถึง DRM-020 (การส่งพารามิเตอร์ตอนขอสิทธิ์ Admin, หน้าต่างคอนโซล, ตัวเปิด .cmd, VC++ 2010 ติดตั้งซ้ำ, `-Items`, เปิดเบราว์เซอร์ในโหมดคำสั่ง, การเลือกหายเมื่อสแกนซ้ำ, ข้อมูลข้อผิดพลาดไม่พอ, เปิดซ้อนหลายหน้าต่าง, ขั้น CI ที่ไม่เคยตรวจจริง)
- เปิดรายงานและลิงก์ผ่าน explorer.exe เพื่อไม่ให้เบราว์เซอร์ทำงานด้วยสิทธิ์ Administrator
